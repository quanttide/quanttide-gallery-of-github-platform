# 特殊文件

这里登记本仓与同类案例集仓库的固定文件，各自承担什么。案例正文是内容，不算特殊文件——它按主题分目录存放，本表只列结构性文件。

## 必备

| 文件 | 职责 |
| :-- | :-- |
| `README.md` | 仓库定位：是什么、给谁看、与同域资产的分工。 |
| `CONTRIBUTING.md` | 这类仓库的具体规范：入库边界、组织方式、案例结构、命名、提交流程、编写规范。 |
| `CHANGELOG.md` | 变更记录，遵循 Keep a Changelog。 |
| `LICENSE` | 许可；文档仓默认 CC BY 4.0。 |

## 按需

| 文件 | 职责 |
| :-- | :-- |
| `AGENTS.md` | 智能体约定：本仓给 AI 的额外规则（如「提交即推送」）。 |
| `ROADMAP.md` | 演进路线：阶段目标与顺序。 |
| `TODO.md` | 待办：暂不执行的事项先记下来。 |

## 内容按主题分目录

非特殊文件（案例、说明）按主题分目录：一个主题一个目录，目录内一篇一个文件、文件名描述主题。如 `second-brain/`（资产子模块操作）、`gallery/`（案例集自身的说明）。
