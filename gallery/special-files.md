# 特殊文件

量潮各仓库的特殊文件是**统一的一套**：文件名与用途在哪都一样；变的是**具体文本**——每类仓库各有自己的 `README.md`、`CONTRIBUTING.md` 等，写法不同。

本表登记这一套文件「有哪些、各自干什么」；具体文本看各仓自己的那几份。案例正文是内容、不算特殊文件，它按主题分目录存放。

## 必备

| 文件 | 用途 |
| :-- | :-- |
| `README.md` | 仓库定位：是什么、给谁看、与同域资产的分工。 |
| `CONTRIBUTING.md` | 贡献规范：本仓的写法与边界。 |
| `CHANGELOG.md` | 变更记录，遵循 Keep a Changelog。 |
| `LICENSE` | 许可。 |

## 按需

| 文件 | 用途 |
| :-- | :-- |
| `AGENTS.md` | 智能体约定。 |
| `ROADMAP.md` | 演进路线：阶段目标与顺序。 |
| `TODO.md` | 待办：暂不执行的事项先记下来。 |

## 内容按主题分目录

非特殊文件（案例、说明）按主题分目录：一个主题一个目录，目录内一篇一个文件、文件名描述主题。如 `second-brain/`（资产子模块操作）、`gallery/`（案例集自身的说明）。
