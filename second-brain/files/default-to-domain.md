# 从 default 到领域

把某个 default（法人主体）第二大脑里属于某领域的内容，迁入该领域第二大脑的对应仓库。适用于 default 名下的全部资产仓库——日志、档案、意图、洞察、路线图、报告、参考、归档、章程、手册、规范、教程、文集、画廊、宣传册、历史、语境。

## 需求

### 情境

quanttide 有多个 default（创始人、实训基地、联盟等），每个 default 都有自己的资产子模块树；领域侧同样有一整套对应仓库。内容写在 default 里，但归属在领域时，要迁到领域第二大脑，而不是在两边各留一份。

### 难点

- 归属不在目录里：内容现在住在哪个仓库，不代表它属于哪个资产；要按正文定性质。
- 目标目录不一定同构：default 侧的目录结构在领域侧可能不存在，落点要按目标仓库的目录体系重判。
- 体例随资产走：迁入不是原文搬家，要按目标资产的写法重写。
- 迁移窗口不能两边都空：先写目标、再删源。
- 指针分散：资产仓、default/领域仓、根仓三层，逐层都要收指针。

## 意图

### 自然语言规则

1. 单一事实源：迁移期间任一时刻，内容至少在一处可找到；完成后源侧不留副本。
2. 按性质定资产：判据是内容讲什么、按什么格式维护，不是它现在住在哪个目录。
3. 按目标定落点：目标侧通常与源侧同构；找不到对应目录时，按目标仓库的目录体系重判，必要时新开目录。
4. 按资产改体例：术语、标题、文件名、段落结构随目标侧。
5. 先写后删：目标侧写就并推送后，才删源。
6. 断链不补链：删掉源侧指向该内容的目录项与导航项，不补跨仓库相对链接。
7. 逐层收指针：目标侧 资产仓 → 领域仓 → 根仓；源侧 资产仓 → default 仓 → 根仓。
8. 以状态为证：目标索引收录、源索引无此内容、两边工作区干净，才算完成。

### 形式化规则

```text
对象：D default 第二大脑，M 领域第二大脑，C 内容，A 资产类型，P 目标落点

操作
  classify(C) → A        按正文定资产类型
  place(A, M) → P        在目标领域按目录体系定落点
  rewrite(C, A) → C'     按目标资产体例重写
  write(M, C')           写目标并推送
  delete(D, C)           删源并推送
  fixpointers()          逐层收指针并推送

不变式（完成后必须全部成立）
  I1 单一事实源：C 只存在于 P
  I2 体例一致：C' 符合目标资产 A 的写法
  I3 索引一致：index(M) 收录 C' ∧ index(D) 不含 C
  I4 无副本：¬exists(D, C) ∧ 源侧无指向 C 的链接
  I5 指针收敛：两侧各层 HEAD = 远端 main
```

## 规格

九阶段流水线，每阶段以状态断言收尾：

1. 筛候选：按标题与正文判断内容属于哪个领域；断言候选落到某个领域。
2. 定性质：确认资产类型；断言能说出它按什么格式维护。
3. 定落点：在目标领域找同名资产仓库，按目标目录体系定具体位置；断言落点存在，或新目录已定名。
4. 改体例：按目标资产写法重写；断言标题、术语、段落结构与目标侧一致。
5. 写目标：在目标资产仓写就，同步 `index.md` 与 `CHANGELOG.md`；断言已推送。
6. 删源：源侧删文，同步 `index.md`、`myst.yml`、`README.md`、`CHANGELOG.md`；断言已推送。
7. 断链：删掉源侧指向该内容的目录项与导航项；断言源侧搜不到该内容。
8. 收指针：目标侧 资产仓 → 领域仓 → 根仓；源侧 资产仓 → default 仓 → 根仓；断言各层指针已提交推送。
9. 复核：两边工作区干净，目标索引收录、源索引无此内容；git 历史即移动凭证。

### YAML 描述

```yaml
meta:
  content: <内容路径>
  domain: <目标领域>
  asset: <资产类型>
  source_repo: <default 侧资产仓>
  target_repo: <领域侧资产仓>
  target_path: <目标落点>

steps:
  - id: classify
    action: 按正文定资产类型
    assert: 能说出内容讲什么、按什么格式维护
  - id: place
    action: 在目标领域按目录体系定落点
    assert: 落点存在，或新目录已由创始人定名
  - id: rewrite
    action: 按目标资产体例重写
    assert: 标题、术语、段落结构与目标侧一致
  - id: write
    action: 写目标资产仓，更新 index 与 CHANGELOG
    assert: 目标仓已推送
  - id: delete
    action: 删源，更新 index、myst、README、CHANGELOG
    assert: 源仓已推送
  - id: unlink
    action: 删源侧目录项与导航项
    assert: 源侧搜不到该内容
  - id: pointers
    action: 两侧逐层收指针并推送
    assert: 各层 HEAD = 远端 main
  - id: audit
    action: 两边对账
    assert: 目标索引收录 ∧ 源索引无此内容 ∧ 工作区干净
```
